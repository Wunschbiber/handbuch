# Wie können wir helfen?

Wunschbiber ist eine kostenlose Web-App für Wunschlisten. Du kannst im Browser Wünsche sammeln und eine Liste erstellen. Zum Teilen meldest du dich mit einem Konto an; Empfänger*innen öffnen den Link im Browser und können — wenn Reservierungen aktiviert sind — freie Wünsche auch ohne Konto reservieren.

In unserer Online-Hilfe findest du Anleitungen für deine [Online-Wunschliste mit Wunschbiber](https://www.wunschbiber.de/). Was hast du heute vor?
